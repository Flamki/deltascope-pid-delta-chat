# Sample provenance

## Supplied engineering drawings

- `samples/lift-gas-compressor.pdf` - provided with the assignment by the user.
- `samples/export-gas-compressor.pdf` - provided with the assignment by the user.

These files are used only as local demonstration inputs. They are not loaded as
hardcoded application state; the same multipart upload pipeline handles them.

## Generated evaluation pairs

The three pairs under `data/eval/` are generated by
`scripts/generate_eval_samples.py`:

1. native equipment revision - pressure, material, and PSV changes;
2. scanned set-point revision - OCR path with trip and alarm changes;
3. native note revision - vent and drain routing changes.

The generator is deterministic. Expected changes and grounded questions are
independently labeled in `eval/datasets/ground_truth.json`.
It uses PyMuPDF's built-in fonts and suppresses generated document IDs, so the
fixtures are byte-stable across repeated runs and do not depend on host fonts.
